關鍵前提：你的兩台音箱都有 Stereo FX Loop

Roland JC-22——stereo FX loop（mono send、stereo L/R return），Series/Parallel 可切換，後段是 2×6.5" stereo 喇叭。Tone King Imperial MKII——stereo FX return，外加 Left/Right 平衡 XLR 輸出。

這個前提把比較的重心整個移走了。原本 Swiss Things vs Buffer++ 是「簡單 vs 靈活」的偏好選擇；一旦音箱端已經是 stereo，Swiss Things 的 mono Loop 2 就不只是少一個功能，而是讓既有的 stereo 投資無法連上去。

各自的獨門功能

對方完全沒有的

只有 Buffer++ 有

  • 真正的 Stereo完整 stereo 訊號路徑，保留 stereo delay／reverb 的空間感。
  • 2 Inputs兩把琴同時上線，腳踩切換，不必拔插線。
  • Input Metering視覺化輸入強度，主動拾音器（EMG）不再盲踩削波。
  • Input Pads可切換輸入衰減，吃得下 synth、active pickup、line level 的熱訊號。
  • Variable Input Loading模擬長線材的高頻衰減，用來調 pickup 的溫暖度。
  • 12 種路由模式同一台機器對應演出、錄音、雙琴、雙音箱等不同需求。
  • 30 dB Boost比 Swiss Things 多 10 dB 的推力。

只有 Swiss Things 有

  • Expression Pedal Jack直接接踏板做音量控制，省下一顆可能吸音的 volume pedal。
  • Flexi-SwitchLatching／momentary 雙模式，長踩瞬發、輕點鎖定。
  • 專用 Loop 角色Loop 1 unbuffered、Loop 2 buffered 寫死，依效果器類型插入即可，不會用錯。
  • 完整公開規格尺寸、電流、阻抗都有數字，pedalboard 空間與供電可以先算好。

優點

  • 極度靈活，一台涵蓋各種場景

  • 雙 input 支援樂器快速切換

  • 要搞懂 12 種模式的差異，學習成本高
  • 設定較複雜，現場臨時改路由容易出錯

  • 尺寸、電流、阻抗官方未公開，難事先規劃板面與供電

Swiss Things

優點

  • 簡單直覺，角色固定不會插錯
  • 針對 dirt 與 time-based 效果器分別最佳化

  • Expression pedal 音量控制，避免額外 tone-suck

  • 只有 1 input，換琴要拔線
  • Loop 角色寫死，無法改變
  • 無 input metering／pads，EMG 削波看不見

該選哪一台

條件式判斷

升級 Buffer++

符合以下任一項
  1. 想充分發揮 Nucleo 的 stereo 殘響
  2. 需要在兩把吉他間快速切換
  3. 需要更靈活的路由配置
  4. 需要 input metering 防止削波
  5. 想要 30 dB boost

結論

建議升級 Buffer++

Swiss Things 本身沒有做錯什麼——它把「兩個 loop、固定角色、現場好踩」這件事做得很好。問題出在它遇上的是一套已經 stereo 化的系統：JC-22 的 stereo 喇叭、Tone King 的 stereo XLR、Nucleo 的 stereo 殘響，全都卡在那個 mono Loop 2 前面。

換句話說，這不是「升級」，而是修正一次器材選擇的錯配。Buffer++ 涵蓋了 Swiss Things 除 expression pedal 與 Flexi-Switch 以外的全部功能，而且與同價位。

唯一例外：如果 expression pedal 音量控制對你是必要的，把 Swiss Things 留著當備用，而不是當主力路由器。原分析已不再推薦「兩者並用」——mono Loop 2 的限制會一路傳到訊號鏈末端。

比較範圍說明 這份比較只涵蓋 Empress Buffer++ 與 EarthQuaker Devices Swiss Things 兩台。知識庫中並未對其他訊號分歧／路由器材（Lehle、Radial、Boss LS-2、One Control、Free The Tone loop switcher 等）做過市場調查，因此「Buffer++ 是唯一選擇」的結論成立範圍僅限這兩台之間的取捨。
