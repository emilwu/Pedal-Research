01 Research人工新增或更新設備規格 YAML 與報告shared/equipment_database/pedals/specs/*.yaml
02 Web-Service執行 /migrate-data，喚起 data-migrator agent.claude/commands/migrate-data.md
03 → Planningdata-migrator 唯讀掃描 Research，映射到 Equipment schema，產生 idempotent SQLscripts/migrations/002_equipment_seed_from_research.sql
04 Planning對 RDS 執行 migration，再依 updatedAt 在 staging / production 之間同步scripts/sync-equipment.sh — isTestData=true 永不同步到 production
05 Web-Service前端與 API 透過 Prisma Equipment model 讀取已落地的資料prisma/schema.prisma

模組開發流程（/design → /build → /validate → /issuework）在 Web 與 App 兩側形狀相同，差別只在 builder 的拆分方式：Web 是 frontend-builder + backend-builder，App 是 app-builder + api-builder，而 api-builder 會跨界寫入 Pedal-Web-Service 的 mobile API。
